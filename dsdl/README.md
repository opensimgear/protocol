# Cyphal definitions

Add canonical application DSDL definitions and document subject/service allocation. No application port IDs or payload schemas are assigned by this scaffold. Each gateway has one chain-local allocator and controller/transceiver path shared by its two sockets. Include stable module identity and the discovery, ownership, freshness, and identity-checked addressing needed by gateway inventory/routing. Node IDs may repeat across independent gateway chains; gateway identity scopes host routes. Validate the selected controller path.
